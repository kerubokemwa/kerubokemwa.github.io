Projects & Lab Challenges

This section contains practical cybersecurity exercises and lab challenges that I have completed as part of my learning journey. Each write-up documents the objective, approach, tools used, findings and lessons learned.

PROJECT 1 — Windows Fundamentals Lab

Platform: Hack The Box

Objective: To understand the fundamentals of the Windows operating system and develop familiarity with Windows components, services, processes and system administration.

What I Worked On: During the lab, I explored how Windows operates and how different system components interact. I also looked at Windows services and processes and how they can be monitored when investigating system activity.

Key Lessons:

  • Understanding the Windows operating system is important in cybersecurity.
  • Processes and services can provide useful information during security investigations.
  • System administration knowledge helps security analysts identify unusual activity.
  • Windows commands and built-in tools can assist with troubleshooting and investigation.

Skills Practiced: Windows | System Administration | Security Analysis | Troubleshooting

LAB CHALLENGE 2 — Network Scanning with Nmap

Tool: Nmap

Objective: To understand how network scanning can be used to discover hosts, identify open ports and gather information about services running on a system.

Approach: I used Nmap to scan a target system and identify available ports and services. I then reviewed the scan results to understand what services were exposed and considered how this information could be useful from a security perspective.

Key Findings:

  • Network hosts can expose multiple services.
  • Open ports can reveal potentially accessible services.
  • Service enumeration provides useful information for security assessment.
  • Not every open port automatically represents a vulnerability, but it provides an area that may require further investigation.

What I Learned: This exercise helped me understand the importance of network reconnaissance during security assessments. It also improved my ability to interpret Nmap scan results rather than simply running the command.

Skills Practiced: Nmap | Network Reconnaissance | Port Scanning | Service Enumeration
